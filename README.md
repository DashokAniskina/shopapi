1. Подготовка базы данных
Откройте MySQL Workbench и подключитесь к вашему локальному серверу.

Создайте базу данных и выполните скрипты. Для этого откройте новые Query Tab и вставляйте содержимое файлов из папки sql/ по очереди:

Сначала выполните schema.sql (создаст базу и таблицы).

Затем functions.sql (создаст 3 функции).

Затем procedures.sql (создаст 7 процедур).

В конце выполните seed.sql (добавит тестовых клиентов и товары).

Примечание: Если Workbench выдает ошибку при создании процедур из-за DELIMITER, создавайте их по одной, копируя блоки кода отдельно.

2. Установка зависимостей (Python)
Откройте терминал (PowerShell или Git Bash) в папке проекта и выполните:

bash
# Создание и активация виртуального окружения
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для Mac/Linux:
source .venv/bin/activate

# Установка библиотек
pip install -r requirements.txt
3. Настройка подключения к БД
Создайте в корне проекта (рядом с manage.py) файл .env и укажите в нем данные для доступа к вашей базе MySQL:

env
DB_NAME=shop_django
DB_USER=root
DB_PASSWORD=ваш_пароль_от_базы
DB_HOST=127.0.0.1
DB_PORT=3306
(Если пароль от базы данных пустой, оставьте значение после = пустым).

4. Запуск проекта
Выполните команду:

bash
python manage.py runserver
После этого откройте браузер и перейдите по адресу: http://127.0.0.1:8000/products/
